# Requirement Traceability

**Baseline:** SRS v1.0 dated 2026-09-05 (repository PDF), expanded test mapping from Software Test Plan v1.0 dated 2026-10-02, plus acceptance criteria and focused requirements in the current project request. IDs and quoted acceptance criteria are retained as given. “Partial” means some code exists, but one or more acceptance criteria remain unverified or incomplete. Sprint 1 test execution is recorded in `TEST_EXECUTION_REPORT.md`; this matrix does not claim untested acceptance criteria passed.

## Mapping confirmation

The user confirmed that the original SRS and Software Test Plan are authoritative. HMS-F-040 remains prescription recording; HMS-F-041 remains prescription-history retrieval; AC-041 requires chronological order; TC-Rx-02 tests retrieval. All Sprint 1 references use F-041 for history. The source documents are not modified. The SRS note says 22 functional requirements while its tables enumerate 23; the STP identifies the count discrepancy. Traceability includes all 23 table IDs.
